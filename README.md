# Kalkulator PICU

Kalkulator cairan, observasi dan skor untuk PICU (Holliday-Segar, Schofield, Caldwell-Kennedy, IWL, balance, GFR Schwartz & pRIFLE, zona TTV, PAT & eskalasi, GCS, COMFORT-B, FLACC, CHEOPS, NRS, NIPS, CRIES, FOUR, CPOT).

Buka di iPhone lewat Safari → Share → **Add to Home Screen**. Setelah dibuka sekali, aplikasi tetap jalan tanpa internet. Tidak menyimpan data pasien.

Alat bantu hitung untuk latihan. Keputusan klinis tetap mengikuti DPJP dan SOP unit.
